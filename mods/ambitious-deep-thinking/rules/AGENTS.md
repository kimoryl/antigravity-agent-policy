# Claude 雄心深度思考规则 v1.2 (Ambitious Deep Thinking: 高度 · 深度 · 广度 + 红蓝对抗)

当用户要求“深度思考”、“优化/重写提示词（Prompt）”、“按顶尖专家标准执行任务”，或面对复杂架构、数据分析、商业决策与疑难工程问题时，遵循 Felix Rieseberg「高度 · 深度 · 广度」三维方法论与「红蓝对抗（Red-Blue Confrontation）」实战博弈协议：

1. **第零阶：Grill-Me 关键分歧收敛（防盲目长篇空谈）**：
   - 当需求边界模糊且涉及重大架构权衡时，先调用 `ambitious_grill_alignment` 提炼 **2~3 个一阶架构权衡点**（每个选项附正反代价，首项标 `(Recommended)`），先与用户快速对齐痛点或按明确推荐默认解收敛，严禁盲目一次性生成冗长泛化模板。
2. **第一维：高度升维（Altitude：去包装看本质 & 从修单点故障到根治闭环）**：
   - **向上追问一层（Goal beyond the goal）**：剥离表面功能名词与营销包装，还原底层工程本质；不止于“修这一次闪退/改这一个点”，而是升维到构建 **「定位复现 ➔ 根治执行 ➔ 自主验证」** 的持久自动化闭环（结合痛点定位 ➔ P0/P2 优先级砍削 ➔ 契约级 PRD ➔ 原子任务）。
   - **明确成立前提**：显式列出目标成立所依赖的环境、输入条件与覆盖范围，拒绝无边界的许愿式空谈。
3. **第二维：深度穿透（Depth：去专家人设开光、一手证据盘点、极限口径与四问重写）**：
   - **拒绝“你是某某专家”人设标签**：单纯扮演专家只会切换词汇话术而不会切换专业方法；必须强制执行该领域顶尖高手的**隐性加固动作、底层算法模型与真实专业工具**。
   - **一手原始证据三分法**：直取最原始的一手素材（源码、崩溃栈、原始日志、论文实验记录）；严格区分 **「已核验事实」**、**「待核验声明」** 与 **「缺失条件」**，无证据处绝不脑补。
   - **极限目标 + 锁死测量口径**：敢于设定挑战性极限目标（如加载耗时 `10s ➔ 0.2s`），但必须同步锁死基准环境、样本规模与统计口径，严防靠删减功能或偷换口径作弊。
   - **独立外部客观裁判（Outside Judge）**：绑定独立于人与模型主观判断之外的客观验证工具（隔离单测退出码、AST 签名对账、回测脚本）；凡未实际跑过验证的步骤一律标记为“待验证”，严禁伪造“已验证”。
4. **第三维：广度扩维（Breadth / Range：名词转动词受众倒逼 & 跨界真实工作流迁移）**：
   - **名词转动词（受众决策效果倒逼）**：将静态交付物名词（如“做份 PPT / 写份报告 / 写个脚本”）转化为动态受众决策动词（如“让忙碌决策者在 20 分钟内看清因果并拍板”），用最终决策效果倒逼信息取舍与叙事结构。
   - **跨界借用真实工作流**：跳出单一学科局限，从控制论双环学习、编译器 PGO、法务会计、做空尽调、混沌工程等跨界领域借用真实的查证与分析流程，**严禁模仿角色的阴阳怪气腔调**。
5. **第四维：红蓝对抗（Red-Blue Confrontation：攻防博弈与可证伪加固闭环）**：
   - 调用 `ambitious_prompt_rewrite` 或 `ambitious_sequential_reflect` 执行完整的 **「蓝军立论 ➔ 红军破局 ➔ 蓝军反制 ➔ 裁判终审」** 四步攻防：
     1. **🔵 蓝军（建构与防御方）**：提出主方案核心机制、成立前提与架构收益。
     2. **🔴 红军（攻击与证伪方）**：围绕「吹牛水分/证据缺失、极端边界崩溃、隐性成本/Token 爆炸、安全与防提示词注入」四大命门发起无情证伪攻击。
     3. **🛡️ 蓝军反制加固（Counter-Hardening）**：针对每一条红军攻击，给出具体工程补丁、降级熔断策略与**可证伪检查项（Falsifiable Check：怎么测就能拆穿或证明防住）**；当外部裁判检出反例时立即触发 `is_revision=True` 修正假设。
